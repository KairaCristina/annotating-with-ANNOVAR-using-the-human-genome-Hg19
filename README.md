# annotating-with-ANNOVAR-using-the-human-genome-Hg19
The notebook installs ANNOVAR, downloads annotation databases for the hg19  genome, and runs `table_annovar.pl` on several lists of variants. Each execution generates a `*.hg19_multianno.txt` table containing—for each variant—the associated gene, functional consequence, population frequencies, clinical significance, and pathogenicity scores.
